# ApplyAI Assistant

Build a modern AI-powered job application assistant called "ApplyAI".

The product is designed to help users automate job applications on Workday career websites using their resume.

Create a production-quality responsive web application using:

- React

- TypeScript

- Tailwind CSS

- shadcn/ui

- Supabase for database/storage where appropriate

IMPORTANT:

Do not build a generic landing page. Build an actual functional application dashboard.

Main application flow:

1. Dashboard

2. Resume Upload

3. AI Resume Parsing

4. Resume Profile

5. Job Analysis

6. Application Autofill

7. Review

8. Application History

9. Settings
